# Public Assets Directory

Place your game assets in these subdirectories:

## /video/
- `opening.mp4` — Opening cinematic (MP4, H.264)
- `opening.webm` — Opening cinematic fallback (WebM, VP9)

## /models/
- `door.glb` — Optional door GLB model
- `manuscript.glb` — Optional manuscript GLB model

## /textures/
- `concrete_diffuse.jpg` — Wall/floor texture
- `wood_diffuse.jpg` — Furniture wood texture

## /audio/
- `ambience.ogg` — Looping background ambience
- `unlock.ogg` — Door/code unlock sound
- `fail.ogg` — Wrong code sound
- `interact.ogg` — Interaction sound
- `glitch.ogg` — Glitch effect sound

## /fonts/
- Custom fonts (optional)

> All files are optional. The game falls back to procedural geometry
> and silent operation if assets are absent.
